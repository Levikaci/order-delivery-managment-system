# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии: [SemVer](https://semver.org/lang/ru/).
Сообщения коммитов: [Conventional Commits](https://www.conventionalcommits.org/ru/v1.0.0/).

## [2.1.1]

### Удалено
- Утилита разового переноса данных из хранилища версий 1.x и её тесты: все установки работают на PostgreSQL, обновление версии выполняется миграциями при старте.

### Документация
- README и документы в `docs/` приведены в соответствие с PostgreSQL: убраны устаревшие сведения о прежнем хранилище, добавлен порядок обновления с резервной копией, исправлено описание `PATCH /api/deliveries/{id}/status` (причина неудачи передаётся в `comment`) и `confirm`.

## [2.1.0]

### Добавлено
- Сессии хранятся в PostgreSQL (в виде SHA-256 токена) и переживают перезапуск сервера (миграция 0004).
- `POST /api/auth/password` — смена пароля; остальные сессии пользователя завершаются.
- Боевой запуск без демо-аккаунтов: `Seed:Demo=false` + `Seed:OperatorPassword`.
- `POST /api/deliveries/{id}/retry` и кнопка «Повторить доставку» в WPF: неудачную доставку можно повторить, история сохраняется.

### Изменено
- Автоподбор курьера выбирает наименее загруженного за последние 24 часа (раньше — первого по имени).

## [2.0.0]

Закрывает issue #1 (замечания аудита).

### Изменено (несовместимо)
- Хранилище переведено на PostgreSQL (в версиях 1.x данные хранились в локальном файле). Для существующих установок была утилита разового переноса данных (удалена в 2.1.1).

### Исправлено
- Обновление схемы БД больше не удаляет данные: версионированные миграции в транзакциях.
- Неудачная доставка (`Failed`) больше не превращает заказ в `Cancelled`: добавлен статус заказа `DeliveryFailed`.
- Деньги хранятся в копейках (`BIGINT`), без двоичной арифметики `double`.
- Создание заказа устойчиво к сбоям назначения курьера; повторный запрос с тем же `requestId` не создаёт дубль.
- Изменение заказа без поля `comment` больше не стирает комментарий.

### Добавлено
- Журнал изменений заказа (состав, адрес, комментарий) с автором и временем.
- HTTP-тесты ролей, некорректного ввода, перезапуска и миграций.

### Удалено
- Неиспользуемые in-memory `OrderService`, `DeliveryService`, `IDeliveryService` и тесты, проверявшие только их.
