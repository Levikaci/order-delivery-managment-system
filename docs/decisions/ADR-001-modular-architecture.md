# ADR-001: Модульная архитектура

**Статус:** принято

## Проблема

Необходимо разделить работу с заказами, доставками, курьерами и клиентами так, чтобы изменение одного направления минимально влияло на остальные.

## Решение

Выделить:

- `OrderModule`;
- `DeliveryModule`;
- `CourierModule`;
- `CustomerModule`;
- `ApiHost`.

## Последствия

Положительные:

- понятная ответственность;
- меньшая связанность;
- удобнее тестирование;
- проще дальнейшее расширение.

Отрицательные:

- появляются дополнительные интерфейсы и DTO;
- необходимо контролировать границы модулей.
