# ADR-002: Взаимодействие через контракты

**Статус:** принято

## Проблема

Прямое использование внутренних классов другого модуля приводит к сильной связанности.

## Решение

Обмен между модулями выполняется через публичные интерфейсы и DTO.

Пример:

```text
OrderModule
    |
    v
IDeliveryService
    |
    v
DeliveryModule
```

## Последствия

Плюсы:

- проще изолированное тестирование;
- контролируемые изменения;
- внутреннюю реализацию можно менять без изменения DTO.

Минусы:

- требуется поддерживать интерфейсы и модели сообщений.
