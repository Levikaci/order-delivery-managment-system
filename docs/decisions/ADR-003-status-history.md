# ADR-003: История статусов доставки

**Статус:** принято

## Проблема

Одного текущего статуса недостаточно для контроля процесса доставки и разбора ошибок.

## Решение

При каждом значимом переходе сохранять запись истории:

```text
StatusHistory
- DeliveryId
- PreviousStatus
- NewStatus
- ChangedAt
- ChangedBy
```

## Последствия

Можно восстановить последовательность выполнения доставки и определить, кто и когда изменил статус.
