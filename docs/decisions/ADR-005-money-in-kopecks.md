# ADR-005: Деньги хранятся в копейках

**Статус:** принято (v2.0.0, issue #1)

## Проблема

Цены хранились как `REAL` (`double`), а в коде использовался `decimal`: значения проходили через двоичную арифметику и могли искажаться.

## Решение

- В БД — `bigint` (`price_kopecks`), в расчётах — `long` (`OrderModule.Money`); переполнение вызывает исключение.
- Наружу (API, WPF) цены отдаются как `decimal` в рублях — формат API не изменился.
- Входная цена округляется до копейки «от нуля» (`0.005 → 0.01`); допустимо `0 … 1 000 000`.
- Цена позиции фиксируется в заказе в момент создания; последующая смена цены товара заказ не меняет.

## Последствия

Суммы заказов точны. Старые `REAL`-цены при импорте пересчитываются `ROUND(price*100)`.
