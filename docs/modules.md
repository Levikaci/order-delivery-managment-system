# Модули системы

| Модуль | Ответственность |
|---|---|
| `OrderModule` | Создание, изменение и просмотр заказов |
| `DeliveryModule` | Создание и управление доставками и статусами |
| `CourierModule` | Данные курьеров и их доступность |
| `CustomerModule` | Данные клиентов и адресов |
| `ApiHost` | HTTP API, валидация, маршрутизация и единый формат ошибок |

## OrderModule

Функции:

- создание заказа;
- получение по ID;
- изменение данных;
- отмена;
- изменение статуса;
- просмотр истории.

Статусы:

```text
Created
Confirmed
Preparing
InDelivery
Delivered
Cancelled
```

## DeliveryModule

Функции:

- создание доставки;
- назначение курьера;
- изменение статуса;
- фиксация времени;
- подтверждение доставки;
- регистрация неудачной доставки.

Статусы:

```text
Created
Assigned
Accepted
InTransit
Delivered
Failed
Cancelled
```

## CourierModule

Функции:

- регистрация;
- получение данных;
- изменение контактов;
- изменение доступности;
- поиск свободных курьеров;
- просмотр назначенных доставок.

Состояния:

```text
Available
Busy
Offline
Blocked
```

## CustomerModule

Функции:

- регистрация клиента;
- получение данных;
- изменение контактов;
- добавление и изменение адресов;
- получение адреса доставки.

## ApiHost

Отвечает за:

- HTTP-запросы;
- валидацию;
- аутентификацию;
- маршрутизацию;
- HTTP-ответы;
- единый формат ошибок.
