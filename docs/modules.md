# Модули системы

| Модуль | Ответственность |
|---|---|
| `OrderModule` | Создание, изменение и просмотр заказов |
| `DeliveryModule` | Создание и управление доставками и статусами |
| `CourierModule` | Данные курьеров и их доступность |
| `CustomerModule` | Данные клиентов и адресов |
| `ApiHost` | HTTP API, валидация, маршрутизация и единый формат ошибок |

## OrderModule

Функции:

- создание заказа (идемпотентно по `requestId`; повтор с другими данными отклоняется кодом `IDEMPOTENCY_CONFLICT`);
- получение по ID;
- изменение данных;
- отмена;
- изменение статуса;
- просмотр истории.

Статусы:

```text
Created
Confirmed
Preparing
InDelivery
Delivered
Cancelled
```

## DeliveryModule

Функции:

- создание доставки;
- назначение курьера;
- фоновое повторное назначение доставок, оставшихся без курьера (`AssignmentRetryService`, настройки в секции `Assignment`);
- изменение статуса;
- фиксация времени;
- подтверждение доставки;
- регистрация неудачной доставки.

Статусы:

```text
Created
Assigned
Accepted
InTransit
Delivered
Failed
Cancelled
```

## CourierModule

Функции:

- регистрация;
- получение данных;
- изменение контактов;
- изменение доступности;
- поиск свободных курьеров;
- просмотр назначенных доставок.

Состояния:

```text
Available
Busy
Offline
Blocked
```

## CustomerModule

Функции:

- регистрация клиента;
- получение данных;
- изменение контактов;
- добавление и изменение адресов;
- получение адреса доставки.

## ApiHost

Отвечает за:

- HTTP-запросы;
- валидацию;
- аутентификацию;
- маршрутизацию;
- HTTP-ответы;
- единый формат ошибок.


---

## Актуальное состояние реализации (v2.0.0)

- В модулях `OrderModule`, `DeliveryModule`, `CourierModule`, `CustomerModule` реализованы **статические правила** (`*Rules.cs`) и `Money`; хранение и сценарии находятся в `ApiHost.Store`. Ранние `OrderService`/`DeliveryService` удалены (ADR-007).
- `OrderStatus` дополнен значением **`DeliveryFailed`** (доставка не удалась, заказ не отменён) — ADR-006:

```text
Created, Confirmed, Preparing, InDelivery, Delivered, Cancelled, DeliveryFailed
```

- `OrderModule.Money` — расчёты в копейках (ADR-005).
- «Просмотр истории» заказа дополнен журналом изменений состава, адреса и комментария (ADR-007) — расширение ТЗ, помеченное как таковое.
- «Отмена», «изменение статуса», «фиксация времени» и «регистрация неудачной доставки» выполняет `Store.ChangeStatus`.
