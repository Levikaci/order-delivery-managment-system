# Область проекта

## Название

**Система управления доставкой заказов**

## Назначение

Система автоматизирует управление доставкой заказов:

- регистрацию заказов;
- хранение данных клиентов и адресов;
- назначение курьеров;
- отслеживание статусов;
- ведение истории изменений;
- фиксацию результата доставки.

## Роли

### Клиент

- создает заказ;
- указывает адрес;
- просматривает заказ;
- получает статус доставки;
- просматривает историю;
- может отменить заказ до передачи в доставку.

### Оператор

- просматривает заказы;
- назначает курьера;
- изменяет статус доставки;
- контролирует выполнение;
- просматривает загрузку курьеров.

### Курьер

- просматривает назначенные доставки;
- принимает заказ в работу;
- отмечает получение;
- подтверждает доставку;
- сообщает о невозможности выполнения.

## Входит в проект

1. Заказы.
2. Клиенты.
3. Адреса.
4. Доставки.
5. Курьеры.
6. Статусы.
7. История статусов.
8. Поиск и просмотр заказов.
9. Контроль доступности курьеров.
10. Основные сведения о выполненных доставках.

## Не входит

- реальные банковские платежи;
- банковские интеграции;
- GPS-навигация;
- оптимизация маршрутов в реальном времени;
- внешние картографические сервисы;
- реальная SMS-интеграция;
- отдельное мобильное приложение;
- интеграция с маркетплейсами.
