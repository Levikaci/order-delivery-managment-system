# Отчет по Этапу 2

## 1. Исходное состояние

Указать фактический результат:

```bash
git status
git branch --show-current
git log -1 --oneline
```

## 2. Выполненные изменения

- создан `.gitignore`;
- создан `.editorconfig`;
- обновлен `README.md`;
- добавлены проектные артефакты;
- добавлены правила Git.

## 3. История коммитов

Вставить фактический результат:

```bash
git log --oneline --graph --decorate --all
```

## 4. Конфликт

Указать:

- какие ветки участвовали;
- какой файл конфликтовал;
- как конфликт был разрешен;
- итоговый коммит разрешения.

## 5. Тег

Указать фактический результат:

```bash
git tag
```

Ожидаемый тег:

```text
v0.1.0
```

## 6. Проверка

Вставить фактические результаты:

```bash
git status
git branch
git log --oneline --graph --decorate --all
git tag
```

Если код уже появился:

```bash
dotnet build
dotnet test
```

## 7. Вывод

Сформулировать, что изменения подтверждаются историей Git и могут быть воспроизведены другим разработчиком.
