# Отчёт по этапу 4 - «Отладка отдельных модулей»

## 1. Цель работы

Проверить работу модулей системы управления доставкой заказов, выявить ошибки обработки входных данных, исправить их и подтвердить результат автоматизированными тестами.

## 2. Обнаруженные дефекты

### Дефект 1. Создание доставки с некорректными данными

**Симптом:** сервис мог принять запрос с пустым адресом доставки.

**Причина:** отсутствовала предварительная проверка обязательных полей запроса.

**Исправление:** добавлена проверка объекта запроса, идентификаторов доставки и клиента, а также адреса. При некорректных данных операция отклоняется.

**Проверка:** добавлен тест `CreateDelivery_WithEmptyAddress_ShouldReturnFalse`.

### Дефект 2. Создание заказа с некорректным идентификатором

**Симптом:** заказ мог обрабатываться с пустым идентификатором.

**Причина:** в `OrderService` отсутствовала проверка `orderId` перед выполнением операции.

**Исправление:** добавлена проверка идентификаторов заказа и клиента, а также адреса. При некорректных данных метод возвращает `false`.

**Проверка:** тест `CreateOrderAsync_WithEmptyOrderId_ShouldReturnFalse`.

## 3. Средства разработки

- C# и .NET 9;
- Visual Studio;
- Git и GitHub;
- xUnit.

## 4. Результаты тестирования

После внесения исправлений выполнена команда:

`dotnet test OrderDeliveryManagementSystem.sln`

По результатам локального запуска успешно пройдены 5 тестов, ошибок тестирования не обнаружено.

## 5. Организация работы

Работа выполнялась в ветке `feature/stage-4-debugging`. Исправления фиксировались отдельными коммитами.

## 6. Вывод

В ходе отладки выявлены и исправлены ошибки проверки входных данных в модулях доставки и заказа. Добавлены тесты для проверки некорректных запросов. Локальный запуск тестов подтвердил успешное прохождение пяти тестов.
